# 进度台（workspace）

个人项目进度工作台 —— 一个只有一屏的作战台：30 秒建好项目，勾任务自动算进度，到期/停滞主动提醒，每天生成可复制的进度总结。

## 使用

- **在线版**：开启 GitHub Pages 后访问 `https://heybrochen-web.github.io/workspace/`
- **本地版**：直接双击 `index.html`，浏览器打开即用
- 数据存浏览器 localStorage，**记得每周用右上角「导出」备份 JSON**

## 功能

- 概览：需要关注（逾期 / 今天到期 / 3 天内 / 停滞）+ 进行中项目
- 进度表：项目 → 关键任务 → 子任务 三层树形，勾选即推进，支持搜索/筛选/折叠
- 任务：单独设优先级、完成日期；支持循环（每天/每周/每月/每 N 天）
- 打卡：一句话记录进展，形成时间线
- 复盘：今日总结 + 近 7 天打卡图 + 一键生成/复制总结文本
- 导入导出 JSON 备份

## 版本管理约定

- `main` 分支 = 可用版本，每次迭代一个 commit，格式 `feat: xxx (vX.Y)`
- 每个可用版本打 tag：`v0.3`、`v0.4`……
- 产品文档在 `docs/PRD.md`，变更记录见 PRD 第 11 节
